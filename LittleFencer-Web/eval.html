📖 使用指引：如何制作标注基准集
  1. 从仓库根目录起服务（datasets 才可访问）：cd LittleFencer && python3 -m http.server 8080
  2. 打开 http://localhost:8080/LittleFencer-Web/annotator.html，导入 datasets/test_videos/ 下的视频（如 test.mp4、sabre1.mp4）
  3. 播放/逐帧（← → 键逐帧）找到每个动作：在动作开始帧点"标记开始"，结束帧点"标记结束"，选择动作类型保存
  4. 标完整段视频后点"导出"，把 JSON 存到 datasets/annotations/（命名如 test_2026-06-10.json）
  5. 回到本页：选同一个视频 + 刚导出的 JSON → 开始评测
  • 标注口径：动作区间从起动帧到落地/恢复完成帧；检测器在动作完成时刻播报，所以容差默认放宽到 0.8s
  • 必须 1x 速度：检测器状态机用墙钟计时，本页强制原速播放，请勿手动调速
  • 调参对比：改 js/config.js 或直接在"参数覆盖"里写 JSON，跑两遍下载两份结果对比 totals.f1
