# LittleFencer Web — 架构与实现

> **版本：** 3.1  
> **更新日期：** 2026-06-10  
> **平台：** Web PWA

## 0. 技术路线（固化决策）

以下决策为 MVP 阶段定版，除非出现硬性障碍不再反复：

| # | 决策 | 内容 | 理由与边界 |
|---|------|------|-----------|
| R1 | **无构建步骤** | 原生 ES Modules，不引入打包器/框架/TypeScript | `python3 -m http.server` 即可开发；代价是无 tree-shaking 与类型检查，靠 `node --input-type=module --check` 做语法把关 |
| R2 | **姿态引擎锁定 MediaPipe Pose（CDN）** | 不打包入仓库，不切换 MoveNet/TF.js | CDN 资源由 SW `mediapipe-cache` 持久缓存，首次加载需联网（已接受）；MoveNet 评估保留为 P3 调研项，不阻塞 MVP |
| R3 | **检测路线：规则状态机为主，DTW 为辅** | 7 个检测器 = 显式状态机 + 几何阈值；DTW 只做事后质量对比，不做触发 | 状态机可解释、可逐项调参（见 R4）；DTW 受限于合成模板，在录得真人模板前不提权 |
| R4 | **阈值全部集中于 `js/config.js`** | 检测器/门控/存储参数一律从 config 读取，禁止新散落硬编码 | 调优、A/B、实地验收改参数只动一个文件 |
| R5 | **置信度双层门控** | 引擎层：9 关键点 ×0.7×10 帧（开始训练）；检测层：12 关节 ×0.5 每帧（运行检测） | 引擎门管"人是否就位"，检测门管"这一帧能不能信" |
| R6 | **SW 策略：预缓存 + stale-while-revalidate** | 同源资源先回缓存、后台刷新；版本号只在清单增删时 bump | 牺牲"更新即时性"换离线优先；模块间版本短暂混用风险已接受（无构建步骤下无指纹方案） |
| R7 | **数据 100% 本地** | IndexedDB 存视频（上限 50 条，收藏豁免），localStorage 存设置/成就 | 零云端零账号是产品定位，不是欠账 |
| R8 | **资产格式** | 内容图 WebP（≤1024px）；PWA 图标/截图 PNG（兼容性） | 仓库内不再接受 MB 级 PNG |
| R9 | **页面拆分维持现状** | index（完整）/ training（专注）双训练页并存 | 已知双页逻辑漂移问题（见 mvp-defects.md D8），MVP 后合并为单页 + 模式开关 |

### 1.2 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 无构建步骤 | 原生 ES Modules | 零工具链依赖，`python3 -m http.server` 即可运行 |
| MediaPipe CDN 加载 | 不打包进仓库 | 避免大型二进制文件入库；浏览器自动缓存 |
| CSS 镜像（非 JS） | `scaleX(-1)` 作用于 Canvas | 单一变换，避免双重镜像错误 |
| 统一速度管线 | 引擎计算，检测器消费 | 过滤后的速度共享；避免重复计算 |
| DTW 仅关键帧触发 | 关键帧检测器控制 DTW | 节省 CPU — DTW 仅在运动结束时运行 |
| IndexedDB 存视频 | 非文件系统 | 全浏览器兼容，无需权限弹窗 |

## 3. 信号处理管线

MediaPipe 原始输出有噪声，依次通过三级过滤器：

### 第一级：异常值剔除器（OutlierRejector）

```
如果关键点跳变 > 肩宽 × 0.15 且 置信度 < 0.8：
    → 使用上一帧位置（拒绝当前测量值）
```

防止单帧故障导致的关节"瞬移"。

### 第二级：置信度加权过滤器（ConfidenceWeightedFilter）

```
alpha = minAlpha + (baseAlpha - minAlpha) × 置信度
过滤值 = alpha × 当前值 + (1 - alpha) × 上一帧值
```

低置信度的关键点获得更重的平滑（信任历史）。
高置信度的关键点获得更轻的平滑（信任测量值）。

### 第三级：One Euro 过滤器

```
截止频率 = minCutoff + beta × |速度|
alpha = 1 / (1 + tau/dt)    其中 tau = 1/(2π×截止频率)
过滤值 = alpha × 当前值 + (1 - alpha) × 上一帧值
```

自适应：静止时平滑（消除抖动），运动时灵敏（消除延迟）。

**参数：** `minCutoff=1.0`，`beta=0.007`，`dCutoff=1.0`

## 5. 动作检测器架构

全部 7 个检测器继承自 `BaseDetector`：

```javascript
class BaseDetector {
    detect(frame, history, velocityTracker = null) → ActionResult | null
    getHipCenter(landmarks) → {x, y}
    getFrontKneeAngle(landmarks) → degrees
    isValidEnGarde(landmarks) → boolean
}
```

**速度数据流：** `Engine.velocityTracker`（基于过滤后的关键点计算）通过 `ActionDetectorManager.detect(frame, history, velocityTracker)` 传递给每个检测器。检测器使用预处理过的速度数据，而非从原始帧重新计算。

### 检测器详情

| 检测器 | 阶段 | 关键阈值 |
|--------|------|---------|
| **弓步检测器** | 空闲→手臂伸展→弓步中→落地 | 手臂伸展 ≥30%，后膝 ≥150°，步距 ≥1.8× |
| **前进步检测器** | 二态（空闲/前进中） | 髋部速度 >0.012/s，距离 >0.04，3 帧稳定停止 |
| **后退步检测器** | 二态（空闲/后退中） | 同前进步，方向相反 |
| **前进弓步检测器** | 空闲→前进中→弓步中→落地 | 前进步后在时间窗口内接弓步 |
| **跳步弓步检测器** | 空闲→起跳→腾空→落地→弓步中 | 双脚抬起，髋部下沉，然后弓步 |
| **飞弓步检测器** | 空闲→伸展→飞行→落地 | 手臂伸展，髋部上升 >0.04，双脚 Y 坐标接近 |
| **格挡反攻检测器** | 空闲→格挡中→反攻中 | 手腕上升 >0.08，然后手臂伸展 >0.7 |

## 7. PWA 配置

- **manifest.json：** 应用名称"小剑客训练"，全屏显示，横屏方向
- **Service Worker（`sw.js`）：** 安装时预缓存全部 HTML/CSS/JS/图片；同源请求 stale-while-revalidate（先回缓存、后台刷新）；MediaPipe CDN 走独立 `mediapipe-cache`
- **缓存版本：** `littlefencer-v9`（仅清单增删时需要 bump，文件内容更新自动生效）
- **图标：** 512×512 启动图标（any + maskable），声明与实际尺寸一致
