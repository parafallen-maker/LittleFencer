# LittleFencer Web — 实地测试验收清单

> **更新日期：** 2026-02-28  
> **测试环境：** 明亮室内，设备横屏放置，距离 2-3 米，画面中仅一名击剑者

---

## 1. 基础检测：全身可见性

| # | 测试场景 | 预期结果 | 通过 |
|---|---------|---------|:----:|
| 1.1 | 全身站立在画面中 | 系统检测到全身，10 帧后提示"全身已检测到！准备训练" | |
| 1.2 | 只露出上半身（脚不在画面中） | **不触发**任何动作识别，提示缺失部位（左脚、右脚） | |
| 1.3 | 只露出头部 | 停留在"等待全身可见"状态，不检测任何动作 | |
| 1.4 | 全身→遮挡脚→恢复全身 | 丢失全身 5 帧后回到等待状态，恢复后重新校准 | |
| 1.5 | 站在画面边缘（身体部分出框） | 坐标超出 5%-95% 范围的部位判定为缺失 | |
